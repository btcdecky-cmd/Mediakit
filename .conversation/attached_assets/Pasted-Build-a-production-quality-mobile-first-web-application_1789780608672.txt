Build a production-quality, mobile-first web application called [YOUR BRAND NAME] — a completely free universal media downloader and media toolkit inspired by services like TTGet, but with a cleaner UI, stronger architecture, and significantly more functionality.

PRODUCT GOAL

Create a fast, modern platform where users can paste a publicly accessible media URL and download or process the media when permitted by the source platform.

The core service must be free for users:

* No subscription
* No credits
* No payment system
* No mandatory account
* No artificial download limits in the application

Do not implement DRM bypassing, private-account extraction, paywall bypassing, or other access-control circumvention. Respect platform terms and copyright restrictions.

URL ANALYZER

When a user submits a URL:

1. Validate the URL.
2. Detect the platform.
3. Detect available media.
4. Retrieve metadata where permitted:
    * title
    * thumbnail
    * duration
    * author/uploader
    * media type
    * available qualities
5. Display available options.
6. Let the user select the desired format and quality.
7. Create a processing job.
8. Process the media on a backend worker.
9. Return a temporary download link.
10. Automatically delete temporary files after a short retention period.

Never expose server credentials, API keys, storage credentials, or internal worker URLs to the browser.
